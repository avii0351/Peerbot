Chapter 05 · Decoupled Architecture

Brain vs Limbs: Why Peerbot never gets obsolete.

Central intelligence, context memory, and MCP integrations execute on Fastpeer. Physical devices remain modular sensory endpoints that require zero firmware rewrites as new AI models emerge.

Layer 04

Physical Limbs (Hardware Endpoints)

Peerbot (voice, screen, camera), robotic arm (document handling), and vendor actuators. Peripheral nodes that sense and actuate without direct peer-to-peer coupling.

Peerbot Robotic Arm Actuators
↕ Universal Hardware Connector (JSON over WebSocket)
Layer 03

Universal Hardware Connector

Single shared event bus. Devices declare capabilities on boot (["audio_stream", "move_xyz"]); Fastpeer dispatches structured task payloads.

Event Bus Low Latency Typed Schemas
↕ Master Agent Orchestration
Layer 02

Fastpeer Brain & Master Agent

Central intelligence maintaining realtor CRM records, CMA reports, contextual memory, LLM orchestration, and workflow state machines.

LLM Engine Context Memory State Machine
↕ Model Context Protocol (MCP)
Layer 01

Digital Services (MCP Connectors)

Gmail MCP, Google Drive MCP, CRM MCP. Secure bridge allowing Fastpeer to query files, monitor correspondence, and sync records.

Gmail MCP Drive MCP CRM Database
